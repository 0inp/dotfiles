## Agent skills

### Issue tracker

Issues are tracked in [GitHub Issues](https://github.com/0inp/dotfiles/issues). See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage labels are used: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

One `CONTEXT.md` per stow module, indexed by `CONTEXT_MAP.md` at the repo root. See `docs/agents/domain.md`.
